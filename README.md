# Linux System Monitor

A Bash-based Linux system monitoring tool that displays important system information such as CPU usage, memory usage, disk usage, uptime, running processes, logged-in users, and network details.

## Features

- System hostname
- Current date and time
- System uptime
- CPU information
- Memory usage
- Disk usage
- Top CPU-consuming processes
- Top memory-consuming processes
- Logged-in users
- IP address

## Technologies Used

- Bash
- Linux
- Git
- GitHub

## How to Run

Clone the repository:

```bash
git clone https://github.com/vivek65666/linux-system-monitor.git
```

Navigate to the project:

```bash
cd linux-system-monitor
```

Make the script executable:

```bash
chmod +x monitor.sh
```

Run the script:

```bash
./monitor.sh
```
